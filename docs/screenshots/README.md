# Web app screenshots

Produced by `cd web && set SHOTS=1&& npx playwright test` against the **synthetic fixture** server (`scripts/web_fixture_server.py`):
candles, signals and numbers in these images are made up for repeatable tests (the pages show the real layout, not real results).
Real-data views are what `arven web` shows on the owner's machine. `docs/lighthouse.json` holds the Lighthouse scores (same fixture).
